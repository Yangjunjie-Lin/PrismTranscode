## Online edition, 2.1

- `@ffmpeg/ffmpeg 0.12.15`: MIT JavaScript Worker wrapper, copyright Jerome Wu and ffmpeg.wasm contributors.
- `@ffmpeg/core 0.12.10`: **GPL-2.0-or-later** WebAssembly engine. It is redistributed unmodified as a same-origin asset, not relicensed as MIT. The license text is in `licenses/FFmpeg-GPL-2.0.txt` and online at https://prismtranscode.vercel.app/FFmpeg-GPL-2.0.txt .
- Upstream source and build recipes: https://github.com/ffmpegwasm/ffmpeg.wasm/tree/v12.15 . Its `packages/core/package.json` declares core 0.12.10. The FFmpeg base is n5.1.4; desktop results on a newer native engine do not certify this engine.
- Source collection with build recipes, dependency sources, upstream license texts and SHA-256 manifest: https://github.com/Yangjunjie-Lin/PrismTranscode/releases/download/v2.1.0-beta.1/FFmpeg-WASM-source-bundle.tar . The collection is generated by `scripts/bundle-wasm-sources.mjs`; it is not a claim of certified byte-for-byte reproduction of the npm binary. Upstream recipes include mutable branch references for some dependencies.
- Engine components include x264/x265, libvpx, LAME, Ogg/Vorbis/Theora, Opus, zlib, WebP, FreeType, FriBidi, HarfBuzz, libass, zimg and the Emscripten runtime. Consult the upstream Dockerfile, each component’s own license and the binary build configuration for exact terms.
- Vite (MIT) and Playwright (Apache-2.0) support development/build/testing. Versions and transitive packages are pinned in `package-lock.json`. An npm vulnerability scan does not audit compiled C/C++ codecs.

Project-written online code remains available under MIT. Distributing or using the combined product also requires compliance with applicable GPL and other component licenses. Do not describe the entire distribution as MIT. No independent license, patent or commercial legal review has been completed.

## Desktop sources and references

| Source | Relationship | Notes |
|---|---|---|
| Original NCM-MP3 Batch v1.0.0 | NCM parsing, platform foundations and synthetic fixtures were retained/extended | Original MIT notices preserved |
| Go | Compiler, standard library and runtime; no third-party Go modules | BSD-style license in `licenses/Go-LICENSE.txt` |
| FFmpeg / FFprobe | External native programs for probing, conversion and verification | Build-dependent licenses; desktop ZIP does not bundle their binaries |
| BtbN FFmpeg-Builds | Optional full GPL engine download | Third-party rolling development build, not a fixed release |
| Gyan builds | Optional release essentials engine | A different component/capability set from a full build |
| SoXR, SVT-AV1, x264/x265, libvpx, LAME, Opus, libaom, libjxl and others | Provided by the selected native FFmpeg build | Their own licenses continue to apply |
| taurusxin/ncmdump | NCM structure/protocol reference | MIT; its executable is not invoked |
| mifi/lossless-cut | Workflow reference for extraction/remuxing | No GUI code or release binary incorporated |
| paulpacifico/shutter-encoder | Workflow reference for batch processing | No GUI code or release binary incorporated |

Desktop and online are distinct distributions: “no bundled FFmpeg binary” applies to the desktop ZIP, not the hosted WebAssembly assets. FFmpeg’s site lists third-party Windows builds; that does not make this app’s optional downloads official FFmpeg-signed binaries. Redistributing a native engine requires its own source/notice/license compliance.

The original 2.0 regression used Linux FFmpeg 7.1.5. The 2.1 Windows regression used BtbN N-126626-g7070fe638e-20260917. Neither statement is a claim of comprehensive testing against the latest stable release or every possible input. Test fixtures are synthetic tones, patterns, transparent blocks and original short subtitles. User-provided songs are not distributed.
