# PrismTranscode 2.0.0 测试摘要

这是 2.0 历史记录。2.1 的 Windows 与在线测试见 ../RELEASE.md；原始历史日志留在本地交付包，不提交公共仓库。

## 本次结果

| 项目 | 结果 | 范围 |
| --- | --- | --- |
| Go 单元测试与 race 检查 | 33/33 顶层测试通过 | NCM、规划、队列、鉴权、安装器、输出安全等 |
| go vet / JavaScript 语法检查 | 通过 | 静态检查，不等于独立安全审计 |
| 真实引擎集成 | 60/60 通过 | 38 个输出预设及保真/异常/恢复检查 |
| 界面组件测试 | 11/11 通过 | 内存页面加载实际 UI，桥接真实本机 API |
| Windows x64 编译 | 通过 | PE32+ GUI；不等于 Windows 实机运行 |
| 同工具链重复构建 | 字节一致 | 同源码与参数连续构建 Windows EXE |

实际媒体引擎：`ffmpeg version 7.1.5-0+deb13u1 Copyright (c) 2000-2026 the FFmpeg developers`。

音频测试素材包含非零的 24-bit 低位数据，验证 WAV→FLAC 的解码 PCM 逐字节一致；不是只用 16-bit 样本补零冒充有效 24-bit 精度。另验证 PNG→PNG/无损 WebP/TIFF 的 RGBA 像素一致、MP4→MKV 原码音视频包一致、NCM 原码 MP3 包一致。用户提供的 NCM 回归成功，原文件哈希保持不变。

## 尚未验证

Windows 原生启动/对话框、普通浏览器 URL 导航与下载交互、引擎联网安装端到端、实际 GPU 编码、最新版 FFmpeg 9.0.1 执行、大文件压力测试、独立安全/许可审查、代码签名。当前 Chromium 环境阻止 URL 导航，因此界面测试明确使用内存页面与本机 API 桥接；没有修改浏览器管理策略。

完整记录见 `unit-tests.txt`、`smoke-report.json`、`smoke-log.txt`、`ui-report.json`、`ui-log.txt`。复现与发布检查见 `../source/docs/ACCEPTANCE.md`。本报告不声称所有输入组合、颜色配置或媒体元数据都已验证，也不把 SHA-256 当作画质评分。
