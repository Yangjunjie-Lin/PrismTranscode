# 在线版使用指南

**简体中文** · [English](USAGE.en.md) · [返回项目](../README.md)

入口：https://prismtranscode.vercel.app 。使用有权处理、来源可信的媒体。在线版不需要账号或安装本机引擎。

## 语言选择

右上角的选择器提供“跟随浏览器 / 中文 / English”。首次访问依次匹配浏览器首选语言列表中的 `zh` 或 `en`，支持地区变体；无匹配时显示英文。中文地区变体统一显示简体中文。

手动选择保存在当前站点的浏览器 `localStorage` 中，键名为 `prismtranscode.language`。选择“跟随浏览器”会删除该值。禁用存储不会阻止使用，但关闭页面后不会记住手动选择。自动模式会响应浏览器发出的语言变更事件；重新打开页面也会重新检测。

切换语言无需刷新，已有文件、独立格式、质量参数、运行中的任务和已完成下载均保留。任务状态、应用错误提示、无障碍标签、标题和说明链接一起更新。JSON 字段名及格式 ID 保持稳定；导出时的说明文字使用当前界面语言，`language` 记录 `zh` / `en`。引擎原始诊断日志不做机器翻译。

## 转换步骤

1. 选择音频、视频、图片或字幕类别，设置默认目标格式、质量、裁剪起点/时长和视频尺寸上限。
2. 点击选择文件或拖放文件。导入时采用当前默认参数，每行也可独立修改目标格式。
3. 修改右侧设置后，点击“将参数应用到未完成任务”才会更新已有任务。已完成任务保持不变；重新转换需移除后再次添加。
4. 点击“开始转换”。首次按需下载约 32 MB 引擎；媒体进入浏览器内存，不上传服务器。任务逐个处理，失败项不会终止整个队列。
5. 完成后逐个点击“下载”。“导出转换记录”提供 JSON，含参数、结果状态、输出 SHA-256、检查说明，以及失败时可用的引擎日志。

“停止当前批次”终止当前 Worker；再次开始会重试未完成任务，跳过已完成任务。移除任务或清空队列会释放对应结果。**刷新/关闭页面会丢失媒体和结果，请先下载保存。**

## 预设与限制

音频：MP3、WAV（16-bit PCM）、FLAC、M4A/AAC、OGG/Vorbis、Opus。视频：MP4/H.264 + AAC、WebM/VP8 + Vorbis。图片：GIF、PNG、JPEG、无损 WebP。字幕：SRT、WebVTT。

- 单文件最多 128 MiB，输入队列最多 384 MiB / 50 个文件；实际解码内存可能显著更高，移动设备可能内存不足。
- GIF 最长 10 秒、宽度最多 480 像素、12 帧/秒。其他图片预设只输出第一帧。JPEG 不保留透明度。
- 起点/时长单位为秒；时长 0 表示直到结束。视频尺寸上限用于缩小，不主动放大。单任务超过 5 分钟会终止。
- Opus 为 FFmpeg 实验性编码器，固定 48 kHz 立体声；高要求请用桌面版 libopus。在线 VP9/libopus 不属于当前经过回归的输出方案。
- 视频只保留第一条画面和音轨；不承诺附件、所有轨道、私有元数据和字幕样式完整迁移。
- HDR 转图片/视频会拒绝；无 HDR 色调映射、GPU 编码、NCM 解码或图像字幕 OCR。NCM 和大文件请用桌面版。
- 检查为 FFprobe 输出结构 + SHA-256，不等同于全文件解码、画质认证或内容安全认证。无损格式不能恢复已丢失的信息。

## 排查问题

引擎加载失败时检查网络、浏览器更新及可用内存。音频输出需要输入包含音轨，视频/图片需要画面，字幕输出需要文本字幕轨。尝试小文件、缩短片段或改用桌面版。损坏文件的原始诊断可从 JSON 报告查看；反馈问题前删除文件名等隐私信息。

建议使用最新版桌面浏览器；当前完整端到端基线是 Chromium。站点和引擎请求仍可能被托管商记入普通访问日志；手动语言偏好是唯一新增的持久化浏览器设置，媒体不会存入 localStorage。详见 [安全与隐私](../SECURITY.md) 和 [第三方许可](../THIRD_PARTY_NOTICES.md)。
