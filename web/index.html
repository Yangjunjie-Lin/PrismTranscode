文件信息

转换引擎

FFmpeg + FFprobe 提供真实的媒体识别与转码。完整引擎支持更多编码器；具体能力以安装后检测结果为准。

只有主动点击安装才联网。下载自 FFmpeg 官网列出的构建方，校验 SHA-256 后安装。BtbN 为最新开发构建，Gyan 为 release essentials；两者均是第三方构建，不是本项目自行编译的引擎。Gyan Essentials 通常不含 SoXR / SVT-AV1。

使用说明

三步完成

添加文件 → 选择输出格式与目录 → 开始转换。右侧参数是新文件的默认值；已有文件可以通过表格下拉框独立选择格式，也可以选中后统一应用参数。

质量与覆盖范围

MP3、AAC、Opus、H.264、H.265、AV1 等为有损编码；提高码率不会补回已经丢失的信息。原码提取 / 重封装不重新编码；FLAC、PCM、FFV1 是避免新增有损压缩的路径，但位深、色度、字幕和元数据仍需核对。

HDR 普通重编码暂时阻止；建议原码重封装。图片输出默认取一帧，GIF 可输出动图。HEIC/HEIF、RAW、专业相机素材等输入取决于引擎版本，不能保证所有变体。图像字幕不做 OCR。音频不能凭空生成真实视频。

任务与隐私

“停止”取消运行任务并删除未提交的输出，可重新开始；不会从中断字节续传。队列和设置会保存在本地。拖放经浏览器复制到本地导入缓存，文件/文件夹选择直接读取原路径。

关闭网页不等于退出后台本地进程，请使用右上角“退出”。软件不联网转换、不带账号登录、不自动升级、不下载媒体、不绕过 Widevine / FairPlay 等 DRM。

结果检查

默认对输出重新探测并完整解码。SHA-256 是输出文件完整性校验值，不是音质评分，也不是与源文件相等的证明。执行命令、警告和失败原因可从文件详情和 JSON 记录查看。

本地数据

Windows 数据目录：%APPDATA%\PrismTranscode。退出软件后可手动清理 imports 导入副本；请勿清理仍要重试的任务输入。完整说明、测试报告、源码与持续集成配置随软件附带。
